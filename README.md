# MFA Consultores Web

## Instrucciones

1. Descomprime este ZIP.
2. Abre la carpeta en VS Code.
3. Ejecuta:

```bash
npm install
npm run dev
```

4. Para generar la versión de producción:

```bash
npm run build
```

La carpeta final para subir a hosting será `dist`.

## Notas
- La página usa React + Vite + Tailwind.
- Imágenes externas vía Unsplash.
- Indicadores con tipo de cambio vía API pública y valores referenciales de UMA/salario mínimo configurados en el código.

MFA Consultores - Sitio web estático sin npm

Este ZIP NO usa npm, React, Vite, node_modules ni package.json.
Para Vercel:
1. Descomprime el ZIP.
2. Sube la carpeta completa a GitHub o arrastra la carpeta a Vercel.
3. En Vercel, si pide configuración, selecciona:
   Framework Preset: Other
   Build Command: vacío
   Output Directory: .
   Install Command: vacío

Archivo principal: index.html

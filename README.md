# ManFa Consultores Landing Page

Landing page profesional para ManFa Consultores.

## Instalación local

```bash
npm install
npm run dev
```

## Build para producción

```bash
npm run build
```

## Subir a GitHub

```bash
git init
git add .
git commit -m "Landing page ManFa Consultores"
git branch -M main
git remote add origin URL_DE_TU_REPOSITORIO
git push -u origin main
```
